🐍 How to Play ITE Pythonpoly

Objective

Be the last player standing! Bankrupt your opponent by making them run out of credits.

Basic Rules

  • Each player starts with ₿1500 credits.
  • Roll two dice and move around the 40-square board.
  • Collect ₿200 each time you pass or land on GO (Run Program).
  • Rolling doubles lets you roll again (3 doubles = Debug Corner).

Properties (Python Topics)

  • Unowned: You may buy it. Answer a Python question for a 20% discount!
  • Opponent owns it: Pay rent. Answer a question to halve the rent!
  • Modules (upgrades): Own all in a color group → buy up to 3 modules each (🔷). Rent increases dramatically!

pip Install Libraries (Railroads)

  • Cost: ₿200. Rent: ₿25 × 2^(count-1) per library owned.
  • 1 library = ₿25, 2 = ₿50, 3 = ₿100, 4 = ₿200

Special Squares

  • Python Challenge 🐍: Draw a card — good or bad events!
  • Code Review 📋: Draw a community card — similar events.
  • Indentation Error / Memory Error ⚠: Pay a tax.
  • Debug Corner 🐛: Just visiting, or stuck here 3 turns (pay ₿50 to leave early).
  • Syntax Error! 💥: Go directly to Debug Corner (do not collect ₿200).
  • Free Refactor ♻: Safe square — nothing happens.

Python Questions

Each property group has 5 questions. Answer A/B/C/D. You'll always see the answer explanation after!
